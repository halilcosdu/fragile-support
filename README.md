# FRAGILE — Privacy Policy & Support

The privacy policy and support page for the iOS game **FRAGILE**, published by Halil Cosdu.

Live page: https://halilcosdu.github.io/fragile-support/

- Privacy Policy URL: `https://halilcosdu.github.io/fragile-support/`
- Support URL: `https://halilcosdu.github.io/fragile-support/#support`

The page is a single self-contained HTML file with no external requests. FRAGILE collects no
data: no account, no network calls, no advertising, no analytics service.
